# EventLog（事记）

以事情为中心的 Android 本地记录 App。规划要做的事，完成后留下耗时、收支和体验；数据可以完整导出。

当前版本 **0.2.0**，浅蓝色界面。数据保存在本机，不需要账号，不申请网络权限。包名 `com.self.daymark`、数据库名和备份中的 `app: "Daymark"` 保持兼容，覆盖安装不会建立另一个账本。

## 日常使用

- **今天**：写名称即可记录。日期、实际耗时、支出、体验文字与 −2 到 2 的评分可补充；无需填写完成时刻、分类或预测。每天保留睡眠确认。
- **计划**：支持每日列表、可选上午／下午／晚上分组、固定开始时间的日程，以及未定日期的待安排事项。预计耗时可选；日程按开始时间和预计耗时展示时间块，重叠安排并列显示。
- **完成**：点击完成，自动生成一条关联的实际记录，可继续补写耗时、费用与体验。预计耗时不会冒充实际耗时。重复点击不会重复生成记录；撤销会移除对应实际记录及支出，再次完成能恢复已填内容。
- **日历**：查看每个月的净收支、活动耗时和睡眠，点击日期回看当天。
- **趋势**：查看周、月、年的资金余额、收支、耗时与体验分布。
- **数据**：设置初始余额、记录独立收支、导出与恢复。独立收支默认选支出，收入仍可切换。

只填名称也能建立待办。没有日期的事项放在待安排；未完成的安排不会被自动丢弃，可以编辑日期重新安排。固定时间日程的完成按钮在下方的当天事项列表中，也可在我的一天中完成。

## 数据与计算

空白表示未知，填 0 才表示明确为零。体验评分为 **−2 非常不值、−1 不值、0 中性、1 值得、2 非常值得**；再点已选评分可以清空。

新记录采用日期和实际耗时，按所选日期累加，不凭耗时推断重叠。旧记录已有的精确区间保持原样，仍按自然日拆分、重叠去重；仅修改文字或金额不会改写旧区间。旧记录修改耗时或日期后转为按日期记录。睡眠单独按区间统计。

资金变化只来自收支流水，计划不扣款。事件费用会生成一笔关联支出，不要再独立记一次。同日新记录使用保存时刻作为记账锚点，补记其他日期默认使用中午；它不代表实际开始或完成时刻。余额从最近的核对点开始累加之后的流水，不等于完整净资产。

删除关联实际记录会使计划回到待办，并移除关联流水。撤销完成保留已填内容用于恢复；删除计划前需先撤销完成。备份保留历史分类、取消事件和预测版本，但界面不再提供这些低频录入项。

## 升级、导出与恢复

0.2.0 使用数据库和备份格式 3，支持从版本 1、2 增量升级与旧备份恢复。旧文字在编辑器中完整合并显示；旧待办转换为新计划，原事件和预测历史保留。版本 1 的 1–5 评分只转换一次；版本 2、3 的 −2 到 2 评分保持原值。

ZIP 包含完整 JSON、各类 CSV 和计算说明，新增计划列表与预计／实际耗时对照。恢复会替换当前账本，需在 App 内确认；恢复前会另存一份当前数据，可从数据页导出。卸载会删除本机数据，请保管导出文件。详细字段见 [数据格式](docs/data-format.md)。

当前日程在本机管理，支持按月选日、按天查看时间块；不包含 Google 日历同步、重复日程、拖拽调整、提醒或多设备同步。

源码、测试、数据库结构和文档纳入 Git；个人数据备份、设备截图、密钥、本机配置与构建产物排除。上一个版本的提交 `cbef43d` 可用于源码对照。旧 APK 不能直接读取新版数据库，回退应用版本应配合升级前备份。

## 开发环境

JDK 21、Gradle 8.13、Android SDK 36、Build Tools 35.0.0；Kotlin 2.2.21、AGP 8.13.2、Jetpack Compose、Room 2.8.4。最低支持 Android 8.0（API 26）。

使用 Android Studio 打开仓库，配置 JDK 和 SDK；或配置 `JAVA_HOME` 与 `local.properties` 中的 `sdk.dir`，在 Windows 执行 `./gradlew.bat assembleDebug testDebugUnitTest`，macOS/Linux 执行 `./gradlew assembleDebug testDebugUnitTest`。首次构建需要下载依赖。

原开发电脑也可在本目录执行以下本机构建辅助脚本：

```powershell
& './.tools/build.ps1'
```

脚本使用本机已有 JDK、Gradle 和依赖缓存离线构建，默认生成调试 APK 并运行单元测试。源 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。`local.properties` 的 SDK 路径以及脚本中的工具版本需要在换电脑时调整。

编译设备测试包：

```powershell
& './.tools/build.ps1' -Tasks @('assembleDebug','testDebugUnitTest','assembleDebugAndroidTest')
```

设备连接并获授权后，可用 Android Studio 或 ADB 安装主 APK 和测试 APK，运行 `com.self.daymark.test/androidx.test.runner.AndroidJUnitRunner`。数据库测试使用独立临时库，不写入正式 `daymark.db`。

测试范围和运行方式见 [测试说明](docs/testing.md)。

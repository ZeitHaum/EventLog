# 下一版：计划与实际记录

状态：2026-10-14，0.2.0 已实现本页功能并通过升级和真机验证。0.1.1 基线提交为 cbef43d。

## 时间以耗时为主

计划可填预计耗时，实际记录可填实际耗时，两者均可选；不要求填写实际完成时刻。需要固定日程时，可额外指定日期和开始时间，用预计耗时确定日历时间块。上午、下午、晚上只表示安排粒度，不自动换算成实际时长。

## 计划与我的一天

- 用“计划”替代低频的概率预测页面，统一管理待安排事项和指定日期的安排。
- 支持类似日历的时间块安排，以及类似“我的一天”的每日待办列表。
- 每日事项可按上午、下午、晚上分组，也可不分组；只写名称即可建立待办。
- 未完成事项保留，可以改期或移到明天。
- 完成按钮提供清晰的勾选反馈和完成数量，并自动生成关联的实际记录。
- 完成后可继续补写体验、实际耗时和费用；不强制打开完整表单。
- 计划耗时不自动冒充实际耗时。重复完成不生成重复记录或重复流水，误点支持撤销。

## 简化记录

- 新建独立收支默认选择“支出”，收入仍可切换。
- “记一件事”只处理已经做过的事，移除“计划中”“已取消”选择、分类、预估和预测入口。
- “做了什么”和“体验到了什么”合并为一个可选文本框，可以只写其中一项。
- 保留名称、可选实际耗时、可选费用，以及现有 −2 到 2 的体验评分。
- 减少大标题、口号和常驻说明，在必要位置保留简短提示。
- 页面结构拟为：今天、计划、日历、趋势、数据。保留睡眠确认、收支统计、日历概览和导出恢复。

## 数据保留与升级

实际升级前重新备份手机最新数据，采用增量迁移。已有事件、流水、睡眠、余额、评分与确认记录应保留；旧文本完整合并，旧分类和预测历史保留在历史数据及导出中。保留计划与实际记录的关联，避免重复计数。

实现后验证：旧库升级与旧备份恢复、耗时与未知值处理、计划完成与撤销、重复点击、改期、关联流水，以及手机上的排版和实际录入流程。

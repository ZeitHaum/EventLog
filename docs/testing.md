# 测试说明

当前版本 0.1.1 的核心验证包含 21 项 JVM 单元测试与 9 项 Android 设备测试。设备测试于 2026-10-13 在一加 Ace 3 上通过；设备测试使用独立临时数据库，界面示例不写入正式账本。

## 单元测试

```powershell
./gradlew.bat testDebugUnitTest
```

覆盖时间重叠与跨日拆分、资金余额、未知与零、预估版本资格、概率统计、−2 到 2 评分校验、旧备份评分转换、JSON/ZIP 往返与 CSV 转义。

## 设备测试

连接 Android 手机或模拟器并允许调试后执行：

```powershell
./gradlew.bat connectedDebugAndroidTest
```

覆盖数据库持久化、恢复事务、观察者更新、历史预测保留、睡眠确认、真实版本 1 数据库迁移至版本 2、重新打开不重复转换，以及日历、表单、评分选择与清空。

`UiScreenshotTest` 会把示例界面截图写到应用的外部文件目录 `verification`，便于检查布局。个人数据、手机截图、诊断日志和本机备份不纳入仓库。

修改数据库或备份格式前，先备份现有数据；迁移测试应核对非空旧记录、空值、评分、关联关系和其他字段。

# 测试说明

当前版本 0.2.0 包含 25 项 JVM 单元测试与 15 项 Android 设备测试，2026-10-14 已在一加 Ace 3 上完成验证。设备测试使用独立临时数据库，界面示例不写入正式账本。

首次真机运行发现两处测试脚本问题：旧结构中部分表不含 indices 数组、日程滚动后未返回列表顶部。修正后相关 5 项复测通过；新增完成提示测试单独通过。25 项单元测试全部通过，15 项不同的设备测试最终均通过。

## 单元测试

```powershell
./gradlew.bat testDebugUnitTest
```

覆盖时间重叠与跨日拆分、按日耗时与未知/零、资金余额、历史预估与概率计算、−2 到 2 评分、旧备份转换、计划关联、JSON/ZIP 往返、CSV 转义以及重叠和跨日的日程时间块。

## 设备测试

连接 Android 手机或模拟器并允许调试后执行：

```powershell
./gradlew.bat connectedDebugAndroidTest
```

覆盖数据库持久化、恢复事务、观察者更新、历史预测保留、睡眠确认，以及真实版本 1、2 的数据库升级到版本 3。计划测试覆盖并发完成不重复、撤销和再次完成保留文字/耗时/费用、改期、删除、重启与恢复。界面测试覆盖默认支出、计划名称单独保存、可选时段和耗时、记录合并文字、评分、日程、日历、趋势和不打断操作的完成提示。

正式账本在覆盖安装前后各留一份校验通过的备份，旧表逐字段对比一致。此过程不卸载、不清空应用数据；升级前的旧版本安装包和源码提交均保留。数据库已升级到 3 后，旧 APK 不能直接读取新版数据库；回退应配合升级前备份。

`UiScreenshotTest` 会把示例界面截图写到应用的外部文件目录 `verification`，便于检查布局。个人数据、手机截图、诊断日志和本机备份不纳入仓库。

修改数据库或备份格式前，先备份现有数据；迁移测试应核对非空旧记录、空值、评分、关联关系和其他字段。
